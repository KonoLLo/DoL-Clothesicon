# clothesicon · 状态栏服装图标

> 给《欲都孤儿 / Degrees of Lewdity》汉化版加一条**状态栏服装图标条**和一个**衣柜悬浮页**：
> 不用翻好几层菜单，抬眼就知道自己现在穿着什么，点两下就能换掉。

- 当前版本：**0.8.2**  
- 依赖：ModLoader `>=2.0.0`、秋枫白桦框架 maplebirch Frameworks `>=5.4.0 <6.0.0`
- 实测环境：DoL **0.5.12.13「深渊」** + Breeze of Lewdity **b1.3.4** + maplebirch **5.4.2**

## 一、功能简介

### 1. 状态栏顶部的图标条

- 位置在**状态栏最上方**（钱数 / 时间 / 星期那一行之下，疼痛·性奋等进度条之上），不占用正文区域。
- 固定 **5 格**：上装 / 下装 / 袜子 / 鞋子 / 衣柜。前四格**纯展示**，没穿也照样占位（空格显示部位名称，半透明）。
- 连衣裙这类同时占上、下装两个部位的套装，会在两格显示同一个套装图标。
- **只有最右侧的衣柜格可以点**，其余格子点了没反应，不会误触。

### 2. 衣柜悬浮页

- 点衣柜格 → 弹出居中悬浮页，按**原版衣柜页签的名称与顺序**列出 11 个部位：
  头饰 / 面饰 / 颈部 / 上装 / 下装 / 内衣上装 / 内衣下装 / 手饰 / 手持物品 / 腿饰 / 鞋子。
  已装备的显示服装图标，未装备的显示部位名称。
- 点任意部位 → 该格**金色高亮**表示已选中，同时第三行行尾出现「脱下」图标按钮；
  点它就脱下当前选中部位的衣物（选中部位没穿时这格半透明、点了没反应）。
- 选中部位后，下方随即展开该部位的衣柜网格，点某件衣服 → **立即穿上**；
  衣柜为空时显示「这里没有可穿的」。手上拿着的衣服（例如刚脱下来的）会以单独一格出现，点它即穿回。
  桌面每行 5 个、移动端每行 4 个，都正好 3 行；下方衣柜默认可视两行，超出时在**容器内直接滚动**，上方的部位格不跟着滚。  
- 关闭方式：右上角「关闭」、点遮罩空白处、按 Esc。

### 3. 已知限制

- 不显示脏衣服堆、`V.store` 里的服装，也不做「取进口袋」这类搬运。
- 图标条固定 4 格（上装 / 下装 / 袜子 / 鞋子），其余部位不在条上——但都能在悬浮页里看到并操作。
- 与原版衣柜一致，`over_upper` / `over_lower` / `over_head` / `genitals` 这类
  原版衣柜没有页签的部位不出现在面板里；这类衣服（含模组外帽）仍需用原版界面处理。

### 4. 安装

1. 打开游戏内 **Mod 管理器**。**如果导入过旧版本，请先删除**——同名模组重复导入会同时加载两份脚本，
   点一次换装会执行两次。
2. 导入 `clothesicon-0.8.2.mod.zip`，按提示刷新 / 重进游戏。
3. 需要已安装 maplebirch Frameworks 5.4.x；图标条会在下一次刷新侧栏时出现（换一张图就生效）。

## 二、更新历史

### 0.8.2（当前版本）— 移动端层级与自适应

- **修复移动端悬浮页被盖住**：查了游戏自身 63 张样式表 / 5641 条规则的层级表后，
  把遮罩与弹窗层级从 98/99 提到 **5000/5001**。移动端那列竖排的疼痛·性奋…进度条是
  `#mobileStats`（z-index 299），旧层级在桌面看不出问题，在手机上会被它直接盖在上面。
- **修复移动端不自适应**：弹窗不再用 `position:fixed` + `left:50%` + `translate(-50%,-50%)` + `vw`
  这套居中（一旦某个祖先带 transform/filter 就会整体偏移并被屏幕裁掉），改成**遮罩 `inset:0` + flex 居中，
  弹窗作为遮罩的子节点** + `max-width/max-height:100%`；包含块算错也只会整体一起偏，不会被裁。
- 格子尺寸不再用 vw 反推，改为渲染完量第一格的**真实宽度**回写 `--ci-cell`，
  所以弹窗被收窄时行高与总高会跟着缩（实测桌面 71px、390×720 手机尺寸下 77px）。
- 矮屏兜底高度由 `100vh` 换成 **`100dvh`**（手机浏览器的 `100vh` 含被地址栏挡住的部分，
  弹窗底部会被裁掉），并保留一条 `100vh` 声明给不支持 `dvh` 的老内核兜底。
- 弹窗挂 `data-ci="keep"`，避免点弹窗内空白处被事件委托一路找到遮罩的「关闭」而误关。

### 0.8.1 — 脱下格位置、容器内滚动、图标条改为纯展示

- 「脱下」格移到**第三行行尾**（`grid-column:-2 / -1`），中间没有按钮的位置保持空白，不插占位元素。
- 去掉「显示全部 / 收起」按钮：弹出框高度已经写死，改为下方衣柜**在容器内滚动**，
  上方的部位格固定不跟着滚。
- **修复一个被固定高度压出来的显示 bug**：容器有确定高度时，Chrome 会按容器去挤隐式网格行，
  实测 71px 的格子被压成 45.58px 一行、三行重叠。补上显式 `grid-auto-rows:var(--ci-cell)` 后行高不再受容器摆布。
  （这个 bug 从 0.8.0 就存在。）
- 侧边栏图标条改为**只有衣柜格可点**，其余四格纯展示（`data-ci` 属性整个不输出，不再白走一遍委托监听）。

### 0.8.0 — 悬浮页内直接脱下 + 高度固定

- 新增「脱下」**图标按钮**（T 恤 + 向下箭头），只在点选了部位之后才出现；点它脱下当前选中部位的衣物。
- 为区分是否已点选部位，给选中部位格加**金色高亮**。
- 删除下方原来的文字版返回 / 脱下按钮。
- 点选部位后下方默认展示两行按钮，按钮大小统一为上方「一行五个」的尺寸。
- **弹出框高度写死**，任何状态下都不跳；移动端改为每行 4 个图标，上方三行 12 格正好显示全部位 + 脱下。

### 0.7.0 — 侧栏描述同步 + 固定高度雏形

- 换装后补调 `<<updatesidebardescription>>`：侧栏「你穿着…」那段文字此前只在 passage 重绘时更新，
  脱完衣服还停在脱下前，必须去开一次原版衣柜才会变。
- 悬浮页高度固定（内容区 340px），内容超出时底部出现「显示全部」，点开变成可滚动的完整列表、按钮变「收起」；
  按钮位置常驻预留，出现 / 消失都不改变总高度。
- 修「这里没有可穿的」被塞进单列、七个字折成三行的问题（`grid-column:1 / -1`）。

### 0.6.0 — 图标条与页签定版

- 图标条改为**固定 5 格**（上装 / 下装 / 袜子 / 鞋子 / 衣柜），没穿也照样占位、空栏显示部位名称；
  每格宽度按侧栏宽推导，不再溢出也不会随内容跳动。
- 悬浮页的部位名称与顺序改为**照抄原版衣柜的 11 个页签**，不再自己造外衣 / 私部等原版没有的页签。
- 套装（连衣裙）在 upper / lower 两格自然显示同一个图标。

### 0.5.0 — 移到状态栏最顶部

- 注入位置从侧栏状态区改到 **`CaptionAfterDescription` 区**（StoryCaption 里 `<<caption_clamp>>` 之后、
  `<div id="statmeters">` 之前），也就是状态栏最上方、各类进度条之上。
- 条上只显示已装备的图标 + 固定在最右侧的衣柜按钮；点衣柜按钮**弹出悬浮页**列出全部部位
  （已装备显示图标，空的显示部位名称），换装不再挤在侧栏里展开。

### 0.4.0 — 第一轮布局整理

- 默认只列出**已装备**的部位，空部位收进「空部位(N)」折叠；部位图标超过上限再叠一层折叠。
- 展开某部位后衣柜以横排网格显示、最多两行，用溢出检测决定要不要给「展开全部」。

### 0.3.0 — 数据模型按实测重写

- 之前按上游原版文档假设的 `V.pocket` / `setup.wardrobe` 在这个 build 里**根本不存在**，
  这是连续两版「什么都没出现」的第二个原因。改为实测模型：
  `V.worn[slot]`（`name === "naked"` 表示空）、`V.carried[slot]`、`V.wardrobe[slot]` + `V.wardrobe.space`、
  `V.store[slot]`、`setup.clothes[slot][i]`（`iconFile` 只存在于定义里，实例被 `clothesDataTrimmer()` 裁过）。
- 换装全部改调**原版 widget**（`generalWearFromWardrobe` / `generalUndress` / `generalOn`），
  不再自己搬运服装对象，诅咒 / 套装 / 孕期 / 史莱姆等限制交回原版判定。
- 图标改为复用原版 `<<clothingicon>>`，配色与眼镜 / 袜子分层和游戏内一致。
- 换装后执行 `<<updatesidebarimg>><<updateallure>>` 同步立绘与魅力值。

### 0.2.0 — 加载路线修正

- 改用 boot.json 的 `scriptFileList` 直接加载脚本：maplebirch 的 `addonPlugin` + `params.script`
  在这个框架版本上**静默不生效**，这是「什么都没出现」的第一个原因。
- 加 `window.clothesiconInstalled` 幂等守卫，避免重复注入。
- 部位表改为按 `V` 中是否真实存在该键来过滤，内置表只作兜底。

### 0.1.1

- 只改元数据：补 `nickName`（Mod 管理器里的中 / 英文显示名）、调整 `addonPlugin` 声明。代码与 0.1.0 相同。

### 0.1.0 — 一拍脑门版

- 侧边栏状态区显示各部位已装备服装的图标；点部位图标就地展开该部位衣柜；点衣柜中的服装快速换装。
- 实时刷新靠框架区域函数在每次 passage 渲染时重跑。
- 部位表按上游文档假设（`over_upper` / `upper_upper` / `breasts_breasts` / `legs_legs` / `socks` / `shoes` …），
  在 0.2.0 / 0.3.0 被实测结论替换掉。
